# Modal Dialog Demo

A simple React modal dialog component demonstrating conditional rendering, state management, and keyboard event handling.

## Features

- Open modal using button click
- Close modal using close button
- Close modal by clicking outside
- Close modal using Escape key
- React Hooks (useState, useEffect)

## Tech Stack

- React
- JavaScript (ES6+)
- CSS

## Installation

1. Clone the repository

git clone <your-repo-url>

2. Navigate to project folder

cd modal-dialog-demo

3. Install dependencies

npm install

4. Start development server

npm start

## Project Structure

src/
 ├── App.js
 ├── index.js
 └── styles.css

## Usage

Click **Open Modal** button to display the modal dialog.  
Interact using mouse or keyboard to close it.
